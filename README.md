# پرگار | Pergar

**مدیریت هوشمند امور مالی شخصی** — ساخته‌شده توسط کوروش پرگار

پرگار یک برنامه‌ی اندروید بومی (Kotlin + Jetpack Compose) برای مدیریت دخل و خرج، نقدینگی و امور مالی روزمره است. رابط کاربری کاملاً فارسی و راست‌به‌چپ با تم تیره‌ی سینمایی، گرادیان‌های آبی-فیروزه‌ای و انیمیشن‌های روان طراحی شده است.

## 🚀 ساخت خروجی APK در GitHub (پیشنهادی)

فایل گردش کار در `.github/workflows/build.yml` قرار دارد و به‌صورت خودکار APK می‌سازد.

1. یک مخزن جدید در GitHub بسازید.
2. کد را آپلود کنید:

```bash
git init
git add .
git commit -m "Pergar — smart personal finance"
git branch -M main
git remote add origin https://github.com/<USERNAME>/<REPO>.git
git push -u origin main
```

3. به تب **Actions** مخزن بروید. گردش کار **Build Pergar APK** به‌صورت خودکار اجرا می‌شود (یا از دکمه‌ی *Run workflow* اجرا کنید).
4. پس از پایان، از بخش **Artifacts** فایل `pergar-apk` را دانلود کنید. شامل:
   - `app-debug.apk` — نسخه‌ی دیباگ، قابل نصب فوری
   - `app-release.apk` — نسخه‌ی ریلیز

> نسخه‌ی ریلیز با کلید دیباگ امضا می‌شود تا بدون نیاز به کلید خصوصی قابل نصب باشد. برای انتشار در Google Play باید کلید امضای اختصاصی خود را تنظیم کنید.

## 🛠️ ساخت محلی

پیش‌نیازها: **JDK 17** و **Android SDK 35**.

```bash
./gradlew assembleDebug
```

فایل خروجی: `app/build/outputs/apk/debug/app-debug.apk`

یا پروژه را در **Android Studio** باز کنید (Android Studio Ladybug یا جدیدتر).

## 🔐 حریم خصوصی

پرگار هیچ حساب کاربری و سروری ندارد. تراکنش‌ها، بودجه‌ها، اهداف و پیامک‌های خوانده‌شده فقط در حافظه‌ی داخلی گوشی ذخیره می‌شوند. پردازش پیامک بانکی به‌صورت محلی انجام می‌شود و هیچ داده‌ای به اینترنت ارسال نمی‌گردد. با حذف برنامه، همه‌ی اطلاعات پاک می‌شود؛ پیش از آن از بخش «پشتیبان‌گیری» در تنظیمات استفاده کنید.

## 📁 ساختار پروژه

```
app/src/main/java/ir/pergar/app/
├── PergarApp.kt              # Application و راه‌اندازی مخزن
├── MainActivity.kt           # اکتیویتی اصلی + صفحه قفل بیومتریک
├── Permissions.kt            # مجوزهای پیامک
├── data/
│   ├── db/                   # موجودیت‌ها، DAO، پایگاه داده، داده‌های اولیه
│   ├── model/                # مدل‌های دامنه
│   ├── repo/                 # FinanceRepository (منطق مرکزی)
│   ├── sms/                  # تحلیل پیامک بانکی + Receiver + اسکنر
│   ├── voice/                # تحلیل گفتار فارسی
│   ├── insights/             # Analytics + InsightEngine (رادار مالی)
│   ├── export/               # خروجی اکسل و پشتیبان‌گیری JSON
│   ├── util/                 # تاریخ جلالی، قالب‌بندی، یادآورها
│   └── prefs/                # DataStore
└── ui/
    ├── theme/                # رنگ‌ها، تایپوگرافی، تم
    ├── components/           # کارت‌ها، نمودارها، آیکن‌ها، دیالوگ‌ها
    ├── screens/              # ۱۸ صفحه‌ی برنامه
    ├── AppViewModel.kt
    └── PergarRoot.kt         # ناوبری و نوار پایین
```
